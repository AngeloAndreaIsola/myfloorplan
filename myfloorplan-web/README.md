# MyFloorplan Web Application

The modern web-based 2D/3D floorplan editor for the **MyFloorplan** ecosystem.

## Key Features

- **2D/3D Floorplan Visualization**: Powered by **Babylon.js** and **Konva**.
- **Modern UI Components**: Using **React**, **DaisyUI**, and **Lucide React**.
- **Dynamic Asset Integration**: Real-time furniture and floorplan updates.

## Technical Stack

- **Vite** with **React (TSX)**
- **TailwindCSS** & **DaisyUI**
- **Zustand** for state management
- **Babylon.js** for 3D rendering
- **Konva** for 2D canvas editing

## Getting Started

### Prerequisites

- [pnpm](https://pnpm.io/)

### Development

Run the development server for the web app:

```bash
pnpm dev
```

The web app is usually available at `http://localhost:5173`.

### Building

To build the production-ready application:

```bash
pnpm build
```

The output will be generated in the `dist` directory.
