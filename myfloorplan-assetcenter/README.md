# MyFloorplan Asset Center

The centralized management for all MyFloorplan assets.

## Overview

- **Storage**: Cloud-based storage for floorplan blueprints, furniture models, and textures.
- **Organization**: Powerful asset tagging and categorization.
- **Integration**: Seamless integration with the MyFloorplan renderer and web application.

## Getting Started

### Prerequisites

- [pnpm](https://pnpm.io/)

### Development

```bash
pnpm dev
```

### Building

```bash
pnpm build
```
