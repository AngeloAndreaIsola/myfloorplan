# MyFloorplan API Service

The high-performance API backend for the **MyFloorplan** ecosystem.

## Overview

- **Powered by**: [Hono](https://hono.dev/)
- **Vite with Node.js**: Fast development and building.
- **RESTful Endpoints**: For project, asset, and user management.

## Getting Started

### Prerequisites

- [pnpm](https://pnpm.io/)

### Development

Run the API service:

```bash
pnpm dev
```

### Building

```bash
pnpm build
```
