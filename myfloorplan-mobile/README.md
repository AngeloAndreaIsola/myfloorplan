# MyFloorplan Mobile App

The mobile-first experience for the **MyFloorplan** ecosystem.

## Key Features

- **Floorplan Editing on mobile**: Intuitive touch controls for easy floorplan management.
- **Project Overview**: Quick access to all MyFloorplan projects.
- **Real-time Sync**: Collaborative features for synchronized floorplan design.
