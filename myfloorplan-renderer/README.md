# MyFloorplan Renderer

The core rendering engine for the **MyFloorplan** ecosystem.

## Overview

- **Visualization**: High-performance 2D/3D floorplan rendering.
- **Physics**: Real-time collision detection and shadow calculations.
- **Adaptability**: Optimized for performance and high-quality visuals.

## Getting Started

### Prerequisites

- [pnpm](https://pnpm.io/)

### Development

```bash
pnpm dev
```

### Building

```bash
pnpm build
```
